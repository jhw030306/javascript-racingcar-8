# javascript-racingcar-precourse

### 기능 목록

- [x] 자동차 이름 입력받기(5자 이하)
  - [x] 이름이 5자 이하인지 확인
  - [x] 중복 이름 허용x
  - [x] 6자 이상 입력 에러
- [x] 자동차 이름 쉼표로 구분 하여 저장
- [x] 시도할 횟수 입력 받기
  - [x] 입력값이 숫자, 양수인지 확인
  - [x] 잘못된 입력 에러처리
- [ ] 각 자동차 별 무작위 수 반환(0~9)
  - [ ] 무작위 값이 4 이상
- [ ] 무작위 값이 4 이상이면 전진 1회 하기
- [ ] 자동차 이름과 전진하는 자동차 출력
- [ ] 경주 게임 완료 후 우승자 출력
  - [ ] 우승자가 여러 명이면 쉼표로 구분

### 고려사항

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현
- 3항 연산자 쓰지 않기
- 함수가 한 가지 일만 하도록 하기
