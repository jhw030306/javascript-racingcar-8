# javascript-racingcar-precourse

### 기능 목록

- [x] 자동차 이름 입력받기(5자 이하)
  - [x] 이름이 5자 이하인지 확인
  - [x] 중복 이름 허용x
- [x] 자동차 이름 쉼표로 구분 하여 저장

- [x] 시도할 횟수 입력 받기

  - [x] 입력값이 숫자, 양수인지 확인

- [x] 0~9까지 무작위 값 가져오기

- [x] 자동차 위치 저장

- [ ] 무작위 값이 4 이상이면 전진 1회 하기
- [ ] 자동차 이름과 전진하는 자동차 출력

- [ ] 경주 게임 완료 후 우승자 출력
  - [ ] 우승자가 여러 명이면 쉼표로 구분
- [ ] ERROR 처리

### 고려사항

- indent(인덴트, 들여쓰기) depth를 3이 넘지 않도록 구현
- 3항 연산자 쓰지 않기
- 함수가 한 가지 일만 하도록 하기

### 에러사항

[ ] 자동차 이름을 5자 초과로 입력

- [ERROR] 자동차 이름은 5자 이하이어야 합니다.
  [ ] 자동차 이름을 중복으로 입력
- [ERROR] 자동차 이름이 중복입니다.
  [ ] 자동차 이름을 공백으로만 입력
- [ERROR] 자동차 이름이 공백입니다.
  [ ] 자동차 이름을 한 개만 입력
- [ERROR] 경주할 자동차는 한 대 이상이어야 합니다.
  [ ] 자동차 이름에 공백 포함
- [ERROR] 자동차 이름엔 공백을 포함할 수 없습니다.
  [ ] 자동차 이름이 숫자로만 이루어짐
- [ERROR] 자동차 이름은 숫자로만 구성될 수 없습니다.

[ ] 시도할 횟수에 문자 입력

- [ERROR] 횟수는 숫자만 입력해야 합니다.
  [ ] 시도할 횟수를 음수로 입력
- [ERROR] 횟수는 음수가 될 수 없습니다.
  [ ] 시도할 횟수를 소수로 입력
- [ERROR] 횟수는 정수여야 합니다.
  [ ] 시도할 횟수가 입력되지 않음
- [ERROR] 횟수가 입력되지 않았습니다.
  [ ] 시도할 횟수를 공백으로 입력
- [ERROR] 횟수는 공백일 수 없습니다.
  [ ] 시도할 횟수를 0으로 입력
- [ERROR] 횟수는 1회 이상이어야 합니다.
  [ ] 매우 큰 수 입력
- [ERROR] 횟수가 너무 큽니다.
